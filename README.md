# Belegmappe

Persönliche Finanz-App als einzelne Webseite: Belege, Verträge und Fristen, Kostenblöcke mit Budget, Reisen, Punkte, Erstattungen.

- Läuft komplett im Browser. Es gibt keinen Server und keine Anmeldung.
- Alle Daten liegen nur auf dem Gerät (IndexedDB). In diesem Repository liegt ausschließlich das Programm.
- Auf dem Handy: Seite öffnen → Browser-Menü → „App installieren“. Danach läuft sie auch ohne Netz.
- Sichern und zurückholen: Übersicht → Export → „5 · Komplett zum Wiederherstellen (JSON)“ bzw. „Sicherung einspielen“.

Neue Programmversion: `index.html` ersetzen. Die Daten auf dem Gerät bleiben erhalten.
